# AI 修图（Android 端）

相册照片选好后，写一句中文就能改图；图片只发到家里的修图网关，不经过 DeepSeek/OpenAI。

本文只讲手机端：入口、配置、使用、与对话的配合、构建和排查。服务端部署、模型文件、端口与调参见 [服务端文档](../server/image-edit/README.md)；接口与实测数据见 [设计稿](image-edit-design.md)。

## 1. 功能一览

- **独立修图页**：选 1–8 张照片，写指令，提交后进「任务」看进度、取消、保存。
- **三种模式**：单张（1 主图）、多图合成（1 主图 + 最多 2 张参考图）、批量（2–8 张，共用一句指令，每张一个 job）。
- **效果预设**：换背景 / 去路人 / 换季节 / 换风格 / 商品图 / 轻修人像；选中后写入指令，仍可手动改。
- **异步任务**：服务端排队执行，App 切后台、断网或进程被杀都不影响；回到页面自动同步状态并补存结果。
- **对话修图**：小砂糖的 4 个工具复用同一套接口，可以直接说「把这张照片背景换成傍晚海边」。
- **自动保存**：任务成功后写进相册，同一结果只存一次（跨进程去重）。

## 2. 入口

| 位置 | 说明 |
| --- | --- |
| 设置 → 小砂糖 → AI 修图 | 「打开修图」进入修图页，「服务设置」进网关配置 |
| 首页右下「面板」 | 快捷面板里的「AI 修图」 |
| 小砂糖页空状态 | 「去 AI 修图」按钮 |
| 对话 | 直接让小砂糖改图、批量改图、查任务、补存结果 |

修图页和设置页都是全屏 overlay，不占抽屉 Tab；关闭后任务继续在服务端跑。

## 3. 首次配置

当前构建已从 `HomelabApp/local.properties` 的 `imageedit.url` / `imageedit.token` 注入默认网关地址和 Token，装好即可用；只有在换服务器、换 Token 或主动清空后，才需要进设置页手动修改。

设置 → 小砂糖 → AI 修图 → 服务设置：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 网关地址 | 空 | 如 `http://192.168.1.10:8094` 或 tailnet 地址；只填到端口，不要带 `/v1` |
| Token | 空 | 服务端 `.env` 的 `IMAGE_EDIT_TOKEN`，只存本机 DataStore |
| 模型标识 | `Qwen/Qwen-Image-Edit-2511` | 仅展示与服务端校验 |
| 推理步数 | 24 | 20–60；本机实测约 8 秒/步 |
| 上传最长边 | 1536 | 768–2048；越大越清晰、上传越慢 |
| 完成后自动保存 | 开 | 关闭后只能在任务卡里手动「保存到相册」 |

点右上角「测试」调 `/health`：显示「模型在线 · 队列 0」即连通；失败会显示具体原因。改完先「保存」。

## 4. 使用流程

### 单张 / 合成

1. 选照片（系统照片选择器，最多 8 张，不申请相册权限）。
2. 选模式：**单张**只取第 1 张；**多图合成**取前 3 张，顺序即「图1/图2/图3」。
3. 选预设或写指令，例如「把背景换成傍晚海边，保留人物五官、发型和衣服不变」。
4. 点「开始修图」→ 切到「任务」看进度；排队中会显示前面还有几个。

### 批量

- 模式选「批量」，至少 2 张、最多 8 张，所有图共用一句指令。
- 一次提交会生成 N 个独立 job，服务端单并发依次跑；8 张约 30 分钟。
- 批量只负责提交，出图后在任务 tab 里逐张保存（自动保存开启时会自动写相册）。

### 任务卡

- 状态：排队中（含队列位置）/ 生成中 / 正在取消 / 已完成（含耗时）/ 失败 / 已取消。
- 操作：进行中可「取消」（排队直接取消，运行中尽力中止）；成功后可「保存到相册」。
- 结果图有服务端缩略图；原图只在提交时上传一次，服务端只留 ≤320px 缩略图。
- 结果在服务端保留 7 天，`result_expired` 表示已清理，需要重新修。

### 与对话配合

| 你说 | 工具 | 行为 |
| --- | --- | --- |
| 「把这张照片背景换成海边」 | `edit_photo` | 最多 3 张参考图，等结果并保存，返回 job_id / seed / 相册路径 |
| 「这 5 张都改成雪景」 | `batch_edit_photos` | 2–8 张，只提交任务，不等待 |
| 「刚才那张修好了吗」 | `list_image_edit_jobs` | 查最近任务状态（只读） |
| 「把刚才那张存下来」 | `save_image_edit_result` | 按 job_id 下载并保存 |

对话和独立页共用同一套设置，不需要配两次。工具返回 `running` 时助手会如实说还在跑，不会假装完成。

## 5. 隐私与权限

- Token 只存本机 DataStore（`allowBackup=false`），不写日志、不提交、不截图。
- 独立页用系统照片选择器读取，不依赖全局相册权限；保存结果需要相册写入权限（Android 10+ 走 MediaStore）。
- 图片只发给家里的网关；对话服务商（DeepSeek 等）只看到工具结果里的文字摘要，看不到照片。
- 不覆盖、不删除原图；结果只新增到相册。

## 6. 预期耗时

| 场景 | 耗时 |
| --- | --- |
| 首次提交（含服务端加载 GGUF） | 3–5 分钟 |
| 单张 1088×1088、30 步 | 约 4 分钟 |
| 单张 1024、20 步 | 约 2–3 分钟 |
| 批量 8 张 | 约 30 分钟（单并发） |

App 侧不显示假的扩散进度，只显示阶段、排队位置和已用时间。

## 7. 构建与安装

前置：JDK 21、Android SDK（platform `android-37.0`、build-tools `37.0.0`）、开启 USB 调试的设备。

```powershell
# 仓库根目录
cd HomelabApp
.\gradlew.bat :app:assembleDebug
```

一键构建 + 安装 + 启动：

```powershell
powershell -ExecutionPolicy Bypass -File .\apply-to-phone.ps1
```

脚本优先用仓库内 `.cache/toolchain`（JDK / Android SDK / Gradle），不存在时回退到系统的 `JAVA_HOME` / `ANDROID_HOME`。换机器时也可用 Android Studio 打开 `HomelabApp/`，Gradle JDK 指到 21 后直接 Run。更细的构建排错见 [build.md](agents/build.md)。

## 8. 排查

| 现象 | 处理 |
| --- | --- |
| 测试连接 401 | Token 不对，重新取服务端 `.env` 的值，注意不要带引号 |
| 测试连接失败 / 顶部服务离线 | 确认网关在跑（服务端文档第 4 节），再确认手机能访问到 8094 |
| 提交后一直 running | 单张约 4 分钟属正常；看 `/health` 的 `queue.running` |
| 提示队列已满（429） | 队列上限 12，等前面的任务结束 |
| 保存失败 `result_expired` | 结果只保留 7 天，重新修一次 |
| 提示没配置 | 设置 → 小砂糖 → AI 修图 → 服务设置 |
| 批量很慢 | 单并发，属正常；步数调低可加快 |
| 缩略图不显示 | 服务端图片接口要 `?token=`，客户端已自动拼接；若仍空白，检查网关地址是否带多余路径 |
